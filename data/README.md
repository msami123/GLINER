# أي بيانات نستخدم؟

النسخة النشطة هي `v2/` فقط، كما يحدد `config.json`.

الملفات القديمة مباشرة داخل `data/` محفوظة للمقارنة التاريخية، وليست مدخلات التدريب الجديد. لا تخلط `all.jsonl` أو `audit.jsonl` أو أقسام النسخة القديمة مع v2.

داخل v2:

- `train.jsonl`: التدريب.
- `validation.jsonl`: اختيار الموديل والعتبة.
- `test.jsonl`: اختبار نهائي بعد تثبيت الاختيارات، ولا يدخل التدريب.
- `sanity.jsonl`: 20 حالة فحص راجعها المساعد، ليست benchmark بشريًا مستقلًا.
- `review_queue.jsonl`: 1,500 حالة غير محسومة، لا تستخدم كتعليقات تدريب قبل مراجعتها.
- `summary.json`: الأعداد ومصادر الملفات وبصماتها وسياسة التقسيم وحدود الثقة.

كل النصوص المستخدمة أصلها ملفات المشروع. الملفات الخام الكبيرة لا تحتاج إلى تنزيلها على PC للتدريب على النسخة الجاهزة. إعادة بناء النسخة تحتاج ملفي المصدر الأصليين المسجلين في `summary.json`.
